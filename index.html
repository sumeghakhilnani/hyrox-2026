Wall Balls Protocol
8:34 → sub 6:00
1
Walk the last 20–30m into the station. HR starts dropping before you pick up the ball.
2
5 deep breaths before touching the ball. Don’t rush this.
3
Start with planned sets: 15+10+10+10. Never go to failure — broken sets cost 30+ seconds.
4
Rest = exactly 3 breaths between sets. Not “when ready.” This separates 8:34 from 6:00.
5
Ball stays at chest height during rest. Putting it down costs 2–3 sec every time.
